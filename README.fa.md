## 🎯 ایده و معماری سیستم (چرا و چگونه؟)

### ❌ چالش موجود:
در کشورهایی مانند ایران که دسترسی به دامنه `api.telegram.org` مسدود است، اتصال مستقیم بردهایی مثل **ESP32** یا **ESP8266** به بات تلگرام غیرممکن است. راه‌اندازی فیلترشکن، پروکسی MTProto یا WireGuard روی میکروکنترلرها نیز به دلیل محدودیت پردازشی و حافظه، بسیار ناپایدار است و مدام قطع می‌شود.

### ✅ راهکار مهندسی این سورس:
در این پروژه از یک معماری **گیت‌وی واسط (Gateway)** استفاده شده است:
1. **سرور واسط لینوکسی (VPS خارج):** یک سرور مجازی خارج از کشور یا بدون فیلتر، مدیریت ربات تلگرام و یک وب‌سرویس فوق سریع بر پایه **FastAPI** را همزمان بر عهده دارد.
2. **ارسال فرمان کاربر:** شما در تلگرام با فشردن دکمه‌های شیشه‌ای وضعیت لامپ را تغییر می‌دهید.
3. **برد ESP32 در خانه:** برد به وای‌فای معمولی خانگی متصل است (بدون هیچ نیازی به VPN). هر ۵ ثانیه یک پینگ سبک HTTP به سرور ارسال کرده، وضعیت رله‌ها را دریافت نموده و لامپ را قطع یا وصل می‌کند.
4. **تشخیص هوشمند آنلاین/آفلاین:** برد ESP32 همراه با هر پینگ، قدرت سیگنال مودم (`RSSI`) و آپتایم خود را می‌فرستد؛ بنابراین در ربات تلگرام دقیقاً مشخص است که برد روشن و متصل است یا خیر!

## 🌟 ویژگی‌های کلیدی

- 🚀 **بدون نیاز به کتابخانه متفرقه در ESP32:** تنها با توابع پیش‌فرض آردوینو (`WiFi.h` و `HTTPClient.h`). حتی نیازی به کتابخانه آردوینوجیسون (ArduinoJson) نیست!
- 🔒 **امنیت دوطرفه:**
  - فقط شناسه‌های عددی ادمین تعریف شده در `ADMIN_IDS` اجازه ارسال دستور دارند.
  - وب‌سرویس با توکن امنیتی اختصاصی (`DEVICE_TOKEN`) محافظت شده تا ربات‌ها و اسکنرهای اینترنتی به رله دسترسی نداشته باشند.
- 💾 **ماندگاری وضعیت (State Persistence):** در صورت قطع برق یا ریستارت سرور، آخرین حالت رله‌ها از روی دیسک بازیابی شده و وضعیت وسایل تغییر نمی‌کند.
- 📶 **نمایش دقیق سیگنال و آنلاین بودن:** آخرین زمان ارتباط، آی‌پی محلی و قدرت آنتن‌دهی بر حسب dBm در متن ربات تلگرام گزارش می‌شود.
- 📱 **پنل وب اختصاصی دارک‌مود:** علاوه بر ربات تلگرام، صفحه وب واکنش‌گرا و مدرن روی پورت `8085` سرور در دسترس است.
- 🛠 **نصب و راه‌اندازی خودکار با ۱ دستور (setup.sh).**

## 🔌 سخت‌افزار و سیم‌کشی

### ۱. نحوه اتصال ماژول رله به برد ESP32

| پین ماژول رله | پین برد ESP32 | توضیحات |
| :---: | :---: | :--- |
| **VCC** | **VIN یا 5V** | تغذیه ۵ ولت بوبین رله (از کابل شارژر) |
| **GND** | **GND** | زمین مشترک |
| **IN1** | **GPIO 26** | پایه فرمان رله اول (لامپ ۱) |
| **IN2** | **GPIO 27** | پایه فرمان رله دوم (لامپ ۲ - اختیاری) |

> ℹ️ **نکته درباره نوع تحریک رله:** اغلب ماژول‌های رله بازار **Active-Low** هستند (با صفر ولت روشن و با ۳.۳ ولت خاموش می‌شوند). این منطق در کدهای آردوینو با متغیر `#define RELAY_ACTIVE_LOW true` لحاظ شده است.

### ۲. نحوه اتصال لامپ به برق شهر ۲۲۰ ولت

> ⚠️ **هشدار ایمنی:** هنگام کار با برق شهر، حتماً دوشاخه را از پریز جدا کرده یا فیوز اصلی را قطع کنید!

۱. سیم فاز برق شهر را به پایه **COM** (مشترک) رله وصل کنید.  
۲. پایه **NO** (Normally Open) رله را به یکی از رشته‌سیم‌های سرپیچ لامپ متصل کنید.  
۳. سیم نول برق شهر را مستقیماً به رشته‌سیم دیگر سرپیچ لامپ متصل نمایید.

## 🚀 راهنمای راه‌اندازی گام‌به‌گام

### مرحله اول: راه‌اندازی سرور لینوکس (VPS)

1. با نرم‌افزار Putty یا ترمینال به سرور متصل شوید:
   ```bash
   ssh root@YOUR_SERVER_IP
   ```
2. وارد پوشه سرور شوید:
   ```bash
   cd esp32-telegram-relay/server
   ```
3. فایل `config.py` را با مشخصات خود بازبینی کنید:
   ```python
   BOT_TOKEN = "توکن_ربات_دریافتی_از_BotFather"
   ADMIN_IDS = [6046868533]         # آیدی عددی تلگرام شما
   DEVICE_TOKEN = "یک_رمز_دلخواه"   # توکن مشترک با ESP32
   SERVER_PORT = 8085
   ```
4. اسکریپت نصب و راه‌اندازی خودکار را اجرا کنید:
   ```bash
   sudo bash setup.sh
   ```
   *اسکریپت محیط پایتون را آماده کرده، پورت 8085 را در فایروال باز می‌کند و سرویس دائم `esp32-relay` را فعال می‌نماید.*

#### مدیریت سرویس سرور
```bash
# مشاهده زنده لاگ‌ها
journalctl -u esp32-relay -f

# ریستارت یا توقف سرویس
systemctl restart esp32-relay
systemctl stop esp32-relay
```

---

### مرحله دوم: پروگرام کردن برد ESP32 در Arduino IDE

1. نرم‌افزار **Arduino IDE** را باز کنید (مطمئن شوید بسته بردهای ESP32 نصب است).
2. برد خود را از مسیر `Tools > Board > esp32 > DOIT ESP32 DEVKIT V1` انتخاب نمایید.
3. فایل `esp32/esp32_relay/esp32_relay.ino` را باز کنید.
4. مقادیر شبکه و آی‌پی سرور را تنظیم کنید:
   ```cpp
   const char* WIFI_SSID     = "نام_مودم_وای‌فای";
   const char* WIFI_PASSWORD = "رمز_عبور_وای‌فای";
   const char* SERVER_HOST   = "128.140.61.50"; // آی‌پی سرور شما
   const int   SERVER_PORT   = 8085;
   const char* DEVICE_TOKEN  = "elecno_secret_key_8849";
   ```
5. برد را با کابل به کامپیوتر متصل کرده و دکمه **Upload** را بزنید.
6. سریال مانیتور را روی باودریت `115200` قرار دهید تا لاگ اتصال و دریافت وضعیت را ببینید.

## 📡 مستندات API وب‌سرویس

تمامی درخواست‌ها با پارامتر `?token=...` اعتبارسنجی می‌شوند.

| اندپوینت | متد | پارامترها | عملکرد |
| :--- | :---: | :--- | :--- |
| `/api/heartbeat` | `GET` | `token`, `rssi`, `uptime` | پینگ دوره‌ای ESP32 و دریافت آخرین وضعیت رله‌ها |
| `/api/status` | `GET` | `token` | دریافت وضعیت به صورت جیسون (JSON) |
| `/api/relay/{id}/raw` | `GET` | `token` | دریافت مقدار خام متنی (`1` یا `0`) |
| `/api/set` | `POST` | `relay` (1-2), `state` (0-1), `token` | کنترل مستقیم رله از نرم‌افزارهای دیگر |
